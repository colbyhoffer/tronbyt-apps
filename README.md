# tronbyt-apps

Personal custom apps for my [Tronbyt](https://github.com/tronbyt/server) server.
Set as the Custom Apps Repository under Settings → Content.

## Apps

### Setlist Tracker (`apps/setlist`)

Shows a concert setlist from [setlist.fm](https://www.setlist.fm) on the 64x32 display:
artist, venue, date + song count, and a scrolling marquee of the songs.

Modes:

- **My last concert** — most recent show marked attended on your setlist.fm account
- **Artist's latest setlist** — newest setlist for any artist

Setup: get a free API key at [setlist.fm/settings/apps](https://www.setlist.fm/settings/apps),
then enter it with your setlist.fm username (or an artist name) in the app settings.

### TCEQ Refinery Alerts (`apps/tceq_alerts`)

Watches the [TCEQ Air Emission Event Report RSS feed](https://www2.tceq.texas.gov/oce/eer/RSSDataFeed.xml)
and shows the newest event whose title contains a keyword (default `REFINERY`): facility name,
county + start time, and incident status + cause (pulled from the event's detail page and cached).
Turn on "Rotate Through All" to step through every match, one per render.

A pixel-art refinery with a flickering flare fills the left 20px; when rotating, the underline
below the header doubles as a position indicator. The sprite is generated by `apps/tceq_alerts/sprite_gen.py`.

Options: keyword, max age (1/2/3 days or the whole ~7-day feed), rotate through all, fetch details on/off,
hide the app when there are no matches, scroll speed, accent color, demo mode.

No API key needed.

## Development


```
pixlet serve apps/setlist/setlist.star
pixlet serve apps/tceq_alerts/tceq_alerts.star
```

Renders live at http://localhost:8080 with a config form.
